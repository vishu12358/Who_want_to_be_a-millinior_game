# Who Wants to Be a Millionaire Game

A simple command-line quiz game written in Python. The game presents 11 multiple-choice questions in sequence, with four possible answers for each question.

## Features

- 11 general knowledge questions
- Four answer choices for every question
- Automatic prize calculation
- Display of the winning amount after every correct answer
- Correct-answer feedback and total winnings at the end

## Prize Levels

The game includes prize amounts ranging from Rs. 100,000 to Rs. 6,000,000.

## Requirements

- Python 3

## How to Run

Open a terminal in the project directory and run:

```bash
python main.py
```

Enter `1`, `2`, `3`, or `4` to select an answer:

- `1` - Option A
- `2` - Option B
- `3` - Option C
- `4` - Option D

The game ends if an answer is incorrect, or after all questions have been answered.
